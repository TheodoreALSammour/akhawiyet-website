# Akhawiyat Beit El Chaar

A responsive public website for the Fersen, Tala2e3, and Chabibe groups. It includes group information, news filtering, an upcoming-events calendar, and a lightweight content manager.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## Publishing

The site can be deployed to GitHub Pages, Netlify, or Vercel. The current content manager stores additions in the editor's browser only (`localStorage`). Before using it as a real multi-user publishing system, connect it to a shared service such as Supabase or Firebase and protect the management panel with authentication.
